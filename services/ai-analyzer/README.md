# AI Contextual Security Analyzer

LLM-assisted reasoning engine for contextual security debt and business logic flaws.

## Responsibilities
- Receives git diffs and deterministic findings from Phase 1.
- Analyzes authorization gaps, insecure defaults, and AI code generation weaknesses.
- Generates contextual remediation guidance and code diffs.
- Supports configurable LLM providers (Gemini, OpenAI, Anthropic, or local endpoints).
